1. 로그인 Assets/google-services.json에서 읽어 온 값이 기본으로 들어가 있습니다

로그인하면 내 UID가 여기에 표시됩니다.

처음 한 번 해야 하는 설정 (로그인 계정 · 관리자 권한)

① 이메일 로그인 켜기 — Firebase 콘솔 → Authentication → Sign-in method → "이메일/비밀번호" 사용 설정. 그다음 Users 탭에서 관리자 계정을 하나 만듭니다. (현재 이 프로젝트는 꺼져 있어서 PASSWORD_LOGIN_DISABLED가 납니다.)

② 관리자 권한 주기 — 아래 규칙을 Firestore → 규칙에 붙여 넣고 게시한 뒤, 로그인해서 위에 뜨는 내 UID를 ADMINS 컬렉션의 문서 ID로 하는 빈 문서로 추가하세요. 이게 없으면 남의 우편함에 못 씁니다.
